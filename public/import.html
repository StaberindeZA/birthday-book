Drag and drop a CSV file here, or click the button above to browse

Expected CSV Format:

The CSV should have the following columns:

"Name","Year","Month","Day","Link to Profile"

Note: Year and Link to Profile are optional. Month should be a number (1-12). Day should be a number (1-31).

Note: To export birthdays from Facebook, the following Chrome extension can be used: Birthday Calendar Exporter for Facebook . This is not an endorsment of this extension, and proper care should be taken installing any extensions.

Preview & Select Entries

Select the birthdays you want to import. You can use the checkbox in the header to select/deselect all.

Duplicate Detection: Entries with matching name, month, and day are marked as duplicates and cannot be selected for import.
